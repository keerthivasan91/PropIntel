## Recording tips

- A screen recording is sufficient. Voiceover is optional; short captions can be used instead.
- Keep browser zoom readable and close unrelated tabs.
- Use only the fictional sample leads or a synthetic enquiry.
- Wait for Gemini responses before moving to the next screen.
- Show a successful task creation and the activity entry.
- Keep the video at or below three minutes.
- Do not show API keys, `.env` files, real customer data, or unrelated browser content.
