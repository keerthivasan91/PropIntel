# Three-minute demo script

Target duration: 2 minutes 45 seconds to 3 minutes. Use the fictional Northstar Homes demo records. Configure the single admin login before recording, and do not show the credentials.

| Time | What to show | Suggested narration |
|---|---|---|
| 0:00–0:25 | Customer page at `/`; submit a sample enquiry and show its confirmation. | “Customers use a separate property enquiry page. It captures the requirement and gives the customer a reference number. The public page can submit an enquiry but cannot view customer records.” |
| 0:25–0:45 | Open `/admin` and sign in, then show the overview. | “The sales workspace is behind a single administrator login. The backend checks a signed session before serving lead, AI, chat or task data.” |
| 0:45–1:05 | Collapse and expand the sidebar; open the lead list. | “The admin workspace keeps navigation compact when needed. Leads are ranked by their latest saved score, with unanalysed records below analysed ones.” |
| 1:05–1:35 | Open Nisha Rao, show Overview and AI Analysis tabs. | “The backend sends the lead and fictional demo company context to Gemini. The model returns six structured fields. The backend validates the response and calculates the numeric score independently.” |
| 1:35–1:58 | Click Ask AI, ask a lead-specific question and show the saved conversation. | “The assistant receives the selected lead, its latest analysis, fictional policy documents and recent conversation history. Conversation history is saved per lead.” |
| 1:58–2:38 | Open Activity & follow-ups, use the AI recommendation, edit the task draft, set a due date and create it. | “The AI only recommends an action. It cannot create a task or contact the customer. The salesperson reviews the draft and explicitly confirms it.” |
| 2:38–3:00 | Show the task in Sales Action Workspace and close with a design trade-off. | “The score is deterministic and explainable rather than a purchase probability generated by the model. The customer intake and internal sales tools are separated, with server-side access control around customer records.” |

## Recording checklist

- Keep the browser at a readable zoom level and close unrelated tabs.
- Start from the public enquiry page so the customer-to-admin workflow is clear.
- Use only synthetic data and a test enquiry.
- Wait for Gemini responses before continuing; do not speed through an unfinished request.
- Show a successful task creation and its activity entry.
- Keep the recording under three minutes.
- Do not show API keys, passwords, `.env` files, real customer data or private browser information.
