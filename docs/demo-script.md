# Three-minute demo script

Target duration: 2 minutes 45 seconds to 3 minutes. Use the seeded fictional Northstar Homes records.

| Time | What to show | Suggested narration |
|---|---|---|
| 0:00–0:20 | PropIntel overview and lead list | “PropIntel helps a real-estate salesperson turn inbound enquiries into prioritized, actionable follow-ups. The sample workspace uses fictional customer data.” |
| 0:20–0:50 | AI priority labels and scores in the lead list | “Leads are ranked by the latest saved score. A salesperson can see which leads need attention first, while leads without an analysis remain at the bottom.” |
| 0:50–1:25 | Open Nisha Rao and show the saved Gemini analysis | “The backend sends the lead and approved demo company context to Gemini. The model returns six structured fields. The backend validates the response and calculates the numeric score independently.” |
| 1:25–1:55 | Ask a lead-specific question in the assistant | “The assistant receives the selected lead, its latest analysis, fictional policy documents and recent conversation history. The history is saved per lead, so the response is not a generic chat.” |
| 1:55–2:35 | Use the AI recommendation, edit the task draft, set a due date and create it | “The model only recommends an action. It cannot create a task or contact the customer. The salesperson reviews the draft and explicitly confirms it. The existing task API writes the task and activity event.” |
| 2:35–3:00 | Show the task in Sales Action Workspace and summarize one trade-off | “The score is deterministic and explainable rather than a purchase probability generated by the model. This keeps AI assistance useful while human decisions remain in control.” |

## Recording checklist

- Keep the browser at a readable zoom level and close unrelated tabs.
- Start from the lead list, not from code or a terminal.
- Wait for Gemini responses before continuing; do not speed through an unfinished request.
- Show a successful task creation and its activity entry.
- Keep the recording under three minutes.
- Do not show API keys, `.env` files, real customer data or private browser information.
